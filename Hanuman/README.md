# Todo List App (TypeScript + Webpack)

This project is a simple Todo List application built with TypeScript and bundled using Webpack. The build process displays progress in the terminal and automatically rebuilds when source files change.

## Features
- Add, complete, and remove todos
- TypeScript for type safety
- Webpack for bundling and hot reloading

## Getting Started

### Install dependencies
```zsh
npm install
```

### Start development server (with build progress)
```zsh
npm run start
```

### Build for production
```zsh
npm run build
```

## Project Structure
- `src/` - TypeScript source files
- `public/` - Static assets and HTML
- `dist/` - Bundled output

## Customization
You can modify the todo app logic in `src/` and the UI in `public/index.html`.
